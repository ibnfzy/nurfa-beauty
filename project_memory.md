# Memory / Rules untuk Nurfa Beauty Project

## Urutan Membaca Dokumen

SEBELUM membaca `implementation_plan.md`, WAJIB baca 3 file ini terlebih dahulu:

1. `design.md` - Design system, warna, tipografi, komponen UI, Tailwind config
2. `rules.md` - Kebutuhan sistem, fitur CRM, routing, sprint, alur checkout
3. `db.md` - Struktur database, tabel, relasi

`implementation_plan.md` berisi versi full implementasi.

## Alasan
Semua detail implementasi sudah dipindahkan ke design.md, rules.md, dan db.md agar lebih terorganisir dan mudah di-maintain.

## Aturan Update Task

**WAJIB:** Setiap kali selesai mengerjakan task atau update sprint, langsung update `tasks.md`:
- Centang `[x]` pada task yang sudah selesai
- Tambahkan task baru jika ada penambahan di luar rencana awal
- Update status progress sprint terkait
